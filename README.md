# Калькулятор рецептов КБЖУ (Recipe Nutrient Calculator)

Приложение для расчета пищевой и энергетической ценности (калории, белки, жиры, углеводы) готовых блюд на основе сырых ингредиентов и коэффициента уварки/ужарки (потерь веса при термообработке).

Проект спроектирован по принципам чистой архитектуры и разделен на изолированное ядро бизнес-логики (библиотеку) и слои доставки (CLI и FastAPI Web API) с логированием результатов в базу данных PostgreSQL.

---

## Быстрый старт с Makefile

Для удобства локальной разработки в корне проекта настроен кроссплатформенный **Makefile**, который автоматически использует локальное виртуальное окружение `.venv`.

### 1. Подготовка окружения
Создать виртуальное окружение `.venv` и установить все зависимости (включая ядро в режиме редактирования `-e`):
```bash
make setup
```

### 2. Запуск локального Web API
Запустить FastAPI сервер в режиме автоматической перезагрузки (reload):
```bash
make run
```
*   Интерактивная документация Swagger API будет доступна по адресу: http://127.0.0.1:8000/docs

### 3. Запуск автоматических тестов
Выполнить полный набор тестов (Smoke-тесты, Unit-тесты ядра с параметризацией, Integration-тесты API с моками СУБД):
```bash
make test
```

### 4. Сборка ядра в виде дистрибутива
Собрать локальную библиотеку `recipe_core` в виде дистрибутивов `.whl` и `.tar.gz`:
```bash
make build-lib
```

### 5. Сборка Sphinx-документации
Сгенерировать HTML-документацию на основе Sphinx и автодокументации докстрингов:
```bash
make docs
```
*   Статические страницы будут доступны в папке: `docs/_build/html/index.html`

## Запуск в Docker (Инфраструктура)

Проект полностью контейнеризирован. Вы можете поднять всю связку приложений (FastAPI Web App + PostgreSQL) с настроенной проверкой готовности (healthchecks) одной командой:

Запуск инфраструктуры:
```bash
make compose-up
```

Остановка инфраструктуры:
```bash
make compose-down
```

---

## Использование CLI (Консольное приложение)

Вы также можете использовать консольный интерфейс для быстрого расчета рецепта из JSON-файла:
```bash
.\.venv\Scripts\python app\cli\main.py sample_recipe.json
```

## Структура проекта

*   `app/` — слои доставки приложения:
    *   `api/` — FastAPI веб-сервис с подключением к БД.
    *   `cli/` — консольный интерфейс командной строки.
*   `packages/recipe_core/` — изолированное ядро расчетов в виде отдельного Python-пакета.
*   `tests/` — тестовое покрытие (smoke, unit, integration).
*   `infra/` — конфигурации Docker Compose для базы данных и приложения.
*   `docs/` — техническая и бизнес-документация (Sphinx + Markdown).
