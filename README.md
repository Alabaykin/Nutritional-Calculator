# Калькулятор питательной ценности рецептов (КБЖУ)

Это учебный проект для курса по инженерии программного обеспечения. Проект рассчитывает пищевую и энергетическую ценность (калории, белки, жиры, углеводы) готового блюда на основе его рецепта (ингредиентов) и коэффициента ужарки/уварки (потери веса при термической обработке).
