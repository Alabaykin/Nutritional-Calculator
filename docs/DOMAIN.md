# DOMAIN: Калькулятор питательной ценности рецептов (КБЖУ)

Пользователь работает с рецептами кулинарных блюд, состоящими из ингредиентов, и рассчитывает их суммарную пищевую и энергетическую ценность (КБЖУ) на все блюдо и на 100 грамм готового продукта с учетом ужарки/уварки.

## Зачем нужен этот документ

Этот документ объясняет, **с какими сущностями работает модуль** и **какую задачу он решает**. По нему можно понять смысл кода еще до чтения реализации.

## Что считается входными данными

Источник данных — файл в формате JSON, описывающий название рецепта, коэффициент уварки и список ингредиентов с их пищевой ценностью на 100 г и весом.

## Основные сущности

**Ингредиент:** Продукт, входящий в рецепт. Характеризуется:
- Названием продукта;
- Сырым весом в граммах;
- Количеством белков, жиров, углеводов и килокалорий на 100 грамм продукта.

**Сырой вес рецепта (Raw Weight):** Суммарный вес всех входящих в рецепт ингредиентов до кулинарной обработки.

**Коэффициент потерь (Loss Coefficient):** Процент сохранения веса при термической обработке (ужарка, уварка, запекание). Например, при ужарке мяса на 20% коэффициент потерь равен `0.8`.

**Конечный вес готового блюда (Cooked Weight):** Масса готового блюда после термической обработки: `Сырой вес * Коэффициент потерь`.

**КБЖУ на 100 г готового блюда:** Относительная пищевая ценность на 100 г готового продукта, которая используется для маркировки готового блюда.

---

## Use-case

Пользователь должен иметь возможность:

1. Считывать рецепты из файлов в формате JSON;
2. Проверять корректность данных ингредиентов (вес продуктов не должен быть отрицательным);
3. Вычислять суммарный сырой вес и итоговый вес готового блюда;
4. Получать абсолютные показатели белков, жиров, углеводов и калорийности на всю порцию блюда;
5. Вычислять относительные КБЖУ на 100 г готового блюда с учетом уварки;
6. Получать детальный консольный отчет о питательной ценности блюда;
7. Использовать API веб-сервиса для сохранения и извлечения истории расчетов в базу данных.

## Ограничения области

В этой версии:

- Не учитываются витамины и микроэлементы;
- Расчет ведется по стандартным формулам уварки без учета летучести веществ;
- Считается, что коэффициент потерь одинаково применяется ко всему объему рецепта;
- Нет интеграции со сторонними дневниками питания.
