# SPECIFICATION: Библиотека расчета КБЖУ кулинарных рецептов

Разработать переиспользуемый Python-модуль, выполняющий валидацию и расчет пищевой и энергетической ценности готовых блюд на основе входящих ингредиентов.

## Формат входных данных

Входной JSON-файл представляет собой структуру следующего вида:

```json
{
  "recipe_name": "Куриная грудка с гречкой",
  "loss_coefficient": 0.8,
  "ingredients": [
    {
      "name": "Куриное филе",
      "weight_g": 200.0,
      "protein": 23.6,
      "fat": 1.9,
      "carbs": 0.4,
      "kcal": 113.0
    }
  ]
}
```

---

## Правила обработки и валидация

- Рецепт должен содержать как минимум один ингредиент. При пустом списке выбрасывается `EmptyRecipeError`.
- Вес каждого ингредиента должен быть строго $\ge 0$. При отрицательном значении веса выбрасывается `NegativeWeightError`.
- Коэффициент потерь (`loss_coefficient`) должен быть строго $> 0$. Данное правило контролируется на уровне Pydantic-схем.
- Все расчеты нутриентов округляются с помощью стандартных математических правил (в тестах проверяются с использованием `pytest.approx`).

---

## Требуемые функции и интерфейс библиотеки

### 1. Модели данных (Pydantic-схемы)

Классы в модуле `recipe_core.models`:
- `Ingredient`: хранит информацию об одном продукте (`name`, `weight_g`, `protein`, `fat`, `carbs`, `kcal`).
- `Recipe`: хранит общие свойства рецепта (`recipe_name`, `loss_coefficient`, `ingredients`).

### 2. Функция расчета

Публичная функция `calculate_recipe` в модуле `recipe_core.calculator`:
- **Принимает**: Объект `Recipe`.
- **Возвращает**: Объект `RecipeCalculationResult` со следующими вычисленными полями:
  - `recipe_name`: Название рецепта.
  - `total_weight_raw`: Исходная масса сырых ингредиентов.
  - `final_weight`: Конечная масса готового блюда (`total_weight_raw * loss_coefficient`).
  - `total_protein`, `total_fat`, `total_carbs`, `total_kcal`: Абсолютные значения нутриентов во всем готовом блюде.
  - `protein_100g`, `fat_100g`, `carbs_100g`, `kcal_100g`: Относительные значения КБЖУ на 100 грамм готового блюда.

  Белки: 59.8 г
  Жиры: 7.1 г
  Углеводы: 62.9 г

Показатели на 100г готового блюда:
